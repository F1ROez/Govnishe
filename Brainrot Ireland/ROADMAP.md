# Дорожная карта

Статусы отделяют реализацию от проверки в Unity.

| Этап | Реализация исходников | Оставшаяся проверка / работа |
|---|---|---|
| 1. Остров, движение, бой, спавн | Выполнена | Компиляция, Play, ощущения камеры и попаданий |
| 2. XP и 12 улучшений | Выполнена | PlayMode-тест очереди уровней и баланс |
| 3. Варианты врагов и боссы | Выполнена | Проверить бой на2-й/5-й минуте, геометрию предупреждений |
| 4. Оформление | Процедурные модели, вода, пальмы, VFX и анимации готовы в коде | Импорт моделей владельца, art review и эффекты огня |
| 5. Меню, рекорды, настройки, звук | Выполнена базовая версия; звук синтезирован | Проверка сохранений на платформах, музыка/аудиомикс |
| 6. Оптимизация и сборки | Пулы, лимиты, команды сборки и тесты подготовлены | Запуск Unity tests, профилирование Windows/Android, исправления, реальные EXE/APK |

Следующий обязательный рубеж: открыть Unity, устранить ошибки импорта/компиляции при наличии, прогнать PlayMode tests и10-минутный забег. Затем Windows build и smoke test на чистом компьютере. Android — после установки модуля Android Build Support и теста на реальном устройстве.

Проект не заявляется завершённым коммерческим релизом. Получен доступ к приватному репозиторию F1ROez/Govnishe; код интегрируется отдельной веткой с сохранением существующих файлов.

## Итерация боевой системы

Реализованы по обратной связи: locked camera, видимая дальность/попадания, подготовка и рывки акул, спокойный старт, рост цены уровней, редактор профиля баланса и мягкая вода. Следующая проверка владельца: игра на отходе; реакция на1-секундный телеграф; первые60 секунд без толпы; сравнение XP и ощущения одного улучшения. Полная визуальная доводка оставлена на поздний этап по пожеланию владельца.

# Brainrot Ireland — правила разработки

Unity 6000.3.11f1, URP 17.3.0, C#. Runtime в Assets/Brainrot/Runtime, Editor отдельно.
Не удалять исходные модели и пользовательские ассеты. Генерируемые ресурсы только в Assets/Brainrot/Generated; сцена Assets/Scenes/BrainrotIreland.unity принадлежит генератору.
Сначала сохранять ручную сцену перед Build Game. Команда пересоздаёт только свою сцену; существующие upgrade assets сохраняет.
Не коммитить Library, Temp, сборки и секреты. Окружение/UI оригинальные процедурные; модели владельца сохранять вместе с источниками, шрифт Island Rounded — производная Nunito/OFL1.1 с лицензией в Art/Fonts. Прочие сторонние ресурсы только с подтверждённой лицензией.
При делегировании закреплять непересекающиеся файлы и заранее согласовывать API. Не менять чужие файлы до завершения задачи.
Обновлять ROADMAP.md и DEVELOPMENT_LOG.md. Перед коммитом запускать Tools/validate_source.py; после изменения поведения — соответствующие Unity PlayMode tests.
Нельзя называть проект проверенным в игре или готовой сборкой без фактического запуска Unity и протокола результатов.
При оптимизации измерять CPU/GPU и GC на Windows и реальном Android. Ограничения количества врагов — бюджеты, а не доказательство FPS.

GameBalance — общий контракт параметров: новые настройки добавлять сюда и снабжать Tooltip/Min/Range. Профиль в Generated/Resources, отдельные upgrades в Assets/Resources/Upgrades не перезаписывать. При обновлении сохранять пользовательские значения. Game Settings должен оставаться доступен без ручного размещения объектов. Попадания должны соответствовать отображаемому сектору, обычный урон врагов — только после телеграфа, рывки — с проверкой пройденного отрезка.

Текущий режим — маленький остров, обычные акулы из океана и волны по последнему заданию владельца. Прокачка и боссы отключены. Акулы всегда преследуют игрока и продолжают идти во время подготовки удара. Игровые надписи и параметры — на русском. Новые герои/оружие расширять данными и отдельным runtime-состоянием способностей. Любая пауза отменяет заряд и очереди невидимых попаданий.

Обычный удар не двигает живого врага импульсом. Физические живые враги не выполняют AI до восстановления. Тела погибших отделять от списка живых, освобождать по бюджету/таймеру и сбрасывать на новом забеге. Заряд и контакты отменять на паузе.

UI использует оригинальный иллюстрированный atlas+JSON: не менять размеры texture/NPOTscale отдельно от rects. Музыка предоставлена владельцем; исходники и MP3 копии сохранять. GameMusic persistent, один активный AudioListener, режим/пауза управляются GameManager/SceneFlow; UI click не должен зависеть от уничтожаемой кнопки.

# Оркаладон

Исходник владельца: F1ROez/Govnishe, main/orcaladon/source/model.glb. Исходный GLB не изменён, Git blob SHA: 6c7cd74aae1efe6d821bbc2475e243fedcb59664.

Orcaladon.fbx — производная для Unity: UV-швы сварены перед упрощением, 10880 вершин/21344 полигона (21774 треугольника после триангуляции), девять деформирующих костей. Поднятая правая ладонь опущена. Для чистой анимации обеих рук создана симметричная версия исправленной стороны и слегка расширена морда; проблемная исходная связь левой ладони с бедром не перенесена. UV-текстура сохранена.

OrcaladonAlbedo.jpg — оригинальные байты baseColor JPEG, извлечённые из bufferView изображения исходного GLB, Git blob SHA dacf65f6a0a47e49882b9dabdff2fe0cc70284fe (687392 байта). Отдельный JPEG в папке textures репозитория отличается от встроенной карты и не соответствует UV этой модели, поэтому сохранён только как пользовательский источник в исходной папке репозитория.

Editor/EnemyModelImporter создаёт Generic prefab ImportedOrcaladon высотой 3.4 м, отдельно от игровой физики. OrcaladonVisual управляет позами дыхания/ходьбы/прицеливания/рывка/замаха/двуручного удара и восстановления по фазам OrcaladonAttack. Сторонние пакеты анимаций не нужны.

FBX повторно импортирован и позы отрендерены в Blender. Unity Editor недоступен; создание prefab, компиляция и игровой вид требуют проверки в Unity.

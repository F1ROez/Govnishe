# Вылет Unity при Play — проверка по журналу

В переданном Editor.log зафиксированы `d3d12: swapchain ResizeBuffers failed (8007000e)` и затем `d3d12: Unrecoverable GPU device error`. Это подтверждает аварийное завершение графического backend DirectX12. Журнал не устанавливает точную причину сбоя драйвера/backend и не доказывает исправность всех игровых систем.

Дополнительно найдены DirectoryNotFoundException при импорте пакетов. Полные пути отсутствующих файлов имеют длину261,263 и267 символов: превышение обычного Windows MAX_PATH — вероятная причина этих отдельных ошибок. Смена на короткий путь и новый импорт устраняют этот фактор.

## Рекомендуемый запуск

1. Полностью закройте Unity Editor и Bug Reporter.
2. Скачайте свежий ZIP ветки codex/brainrot-ireland и распакуйте. Сохраните старую папку, если меняли проект.
3. Перенесите вложенную папку проекта (внутри Assets, Packages, ProjectSettings и START_UNITY_DX11.bat) в **C:\UnityProjects\BrainrotIreland**. Не открывайте внешнюю папку репозитория. Не переносите Library и Temp из старой копии — свежему проекту нужен чистый импорт.
4. Дважды нажмите **START_UNITY_DX11.bat**. Он открывает Unity6000.3.11f1 через **DirectX11** с параметром -force-d3d11. Установленная версия Unity должна находиться в стандартном каталоге Unity Hub; иначе измените путь BRAINROT_UNITY_EDITOR в файле через Блокнот.
5. Дождитесь окончания импорта. В заголовке Unity должно быть **DX11**. Выполните Tools → TungTung → Build Game, откройте Assets/Scenes/BrainrotIreland.unity и нажмите Play.

Запускайте эту копию через BAT: он задаёт DirectX11 для процесса редактора. Настройки графического API Windows-сборки на процесс редактора не влияют; существующий ProjectSettings не изменялся.

Если вылет повторился, сохраните новый `%LOCALAPPDATA%\Unity\Editor\Editor.log` **до следующего запуска Unity** и передайте его для анализа. Если вылета нет, но Console показывает красные ошибки, передайте первую полностью.

Файл запуска проверен чтением исходника; запуск Unity/DirectX11 в облаке невозможен. Исправление требует проверки на компьютере владельца.

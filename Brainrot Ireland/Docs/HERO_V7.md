# Сахур: управление и анимации v7

18 ноября 2026. Обновление героя и подсказок управления.

Нижняя широкая лента управления удалена. Рядом с сильной атакой указаны ЛКМ/удержание/отпускание; рядом с рывком — Пробел. Под способностями расположены обычный удар, Shift для бега и V с текущим режимом камеры. На мобильном экране клавиатурные подсказки скрыты.

Используется существующий Generic-скелет модели ZAHUR с исходным Idle и созданными в проекте ходьбой/бегом; удары и двуручный замах накладываются процедурно на кости. Ходьба и бег теперь смешиваются в одном BlendTree, скорость сглаживается, корпус получает небольшой наклон по направлению движения. Ноги дополнены перекатом стопы. Удары ускоряются к моменту контакта и плавно завершаются; бита сохраняет длину во время взмаха. Движение назад и вбок использует общий цикл ног с направленным наклоном корпуса — отдельных записанных боковых/задних клипов пока нет.

Камера при полном заряде: фабричное приближение 1,65 м и сужение FOV на 17°, быстрый возврат FOV с параметром .10 с; сила отдачи учитывает настройку тряски. Короткий отпущенный клик в последние .16 с восстановления сохраняется для следующего удара. Буфер очищается при отмене/паузе/захвате. Перемещение персонажа не ждёт анимацию; поворот использует независимое от FPS сглаживание.

Новые сторонние анимационные пакеты для работы обновления не требуются. Ретаргетинг случайного Humanoid-клипа на этот Generic-скелет не происходит автоматически.

Если понадобится заменить движения на профессиональные клипы, подходящие источники: [Mixamo](https://www.mixamo.com/) (Idle, Walking, Running, Baseball Swing) и [Kevin Iglesias](https://keviniglesias.com/) (Human Melee / Basic Character Animations). Для этой модели сначала потребуется настроить Humanoid Avatar или перенести движение в Blender на текущий metarig. Одного копирования FBX в Assets недостаточно. Текущие удары остаются собственной хореографией проекта.

Обновление: закрыть Unity, заменить Assets/Brainrot из ZIP, открыть проект и дождаться компиляции. Выполнить Tools → TungTung → Обновить графику и материалы для обновления профиля и сгенерированной модели. Сцены пересоздавать не требуется. Сохранённые ручные настройки профиля сохраняются; прежние фабричные значения подачи сильного удара обновляются.

Ручная приёмка: ходьба → бег → остановка; движение назад/боком с фиксацией камеры; обычный удар и быстрые повторные нажатия; полный заряд → отпускание с попаданием/промахом; пауза во время замаха; захват осьминогом; новый забег; масштаб модели 0.7/1/1.5; камера у пальмы. Бита не должна менять длину при атаке. Короткое приближение/отдача не должны оставаться после отмены атаки.

Unity Editor здесь отсутствует. Автоматическая статическая проверка не подтверждает внешний вид анимаций, C# семантику и ощущения от управления; это требует запуска на машине владельца.

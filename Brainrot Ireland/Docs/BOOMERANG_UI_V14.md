# Бумеранг и новый интерфейс

Короткий ЛКМ теперь бросает биту вперёд и возвращает её к текущему положению руки. Каждый враг получает не более одного попадания на каждом направлении. Контакт проверяется по пройденному отрезку, чтобы низкая частота кадров не пропускала цели. Применяются текущие урон, критический шанс и вампиризм; обычный бросок не отбрасывает. Старая скрытая мили-атака к броску не добавляется. Пока бита летит, следующий бросок и сильная атака недоступны. Полный заряд удержанием ЛКМ и сильный удар после возвращения сохранены. Пауза, лавка, отключение, захват и новый забег отменяют полёт и возвращают биту в руку. Параметры находятся в GameBalance.Boomerang.

Лавка предлагает три разных случайных товара из прежних четырёх улучшений. Ассортимент фиксируется на волну; повторное открытие, стрелки и точки его не меняют. Каждый товар покупается один раз за волну и остаётся проданным. Следующая волна обновляет предложения; максимальные ранги исключаются. Новые типы улучшений не добавлены.

UI перестроен по последним изображениям: высокие бирюзовые карточки без песочной подложки, отдельные прозрачные иконки, ранги и цена с монетой; кремовая пауза с бирюзовой рамкой; компактные кнопки меню, способности, монеты и волна. Стрелки и точки лавки выбирают карточку. Живые кнопки сохраняют пружинные наведение/нажатие. Настройки/рекорды/скины используют ту же гладкую кремовую поверхность. Для открытой лавки включается существующее размытие мира на среднем/высоком качестве.

Четыре PNG оформления автоматически собираются из Generated/Editor/MenuArtPayloads: добавлен IslandUpgradeIcons с прозрачными предметами. Копировать необходимо всю Assets/Brainrot, включая Editor, Generated/Editor и .meta. Оригиналы предыдущих иллюстраций сохранены.

Проверено статически125C# без ошибок,32Python-теста проходят. Добавлены PlayMode-регрессии полёта, двух направлений, отмены, ассортимента/проданных товаров, UI и покупки случайного предложения. Unity, настоящий рендер, деформации и HLSL здесь не запускались; совпадение пиксель-в-пиксель с референсом не утверждается.

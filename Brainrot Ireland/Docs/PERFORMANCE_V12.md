# Оптимизация v12 —19 ноября2026

## Изменения

- Производная сетка Оркаладона:92 190→18 437 треугольников (−80%),60 003→18 216 вершин (−70%). Blender Decimate сохраняет UV; UInt16-индексы уменьшают буфер. Исходный GLB/текстура остаются неизменными. Геометрия декодируется только в Editor, существующий prefab пересобирается по новой подписи исходников.
- NPC больше не принудительно обновляют skinned mesh вне видимости; Animator использует CullUpdateTransforms. Невидимые визуальные pose-drivers пропускают обновление костей. AI и проверки атак продолжают работать.
- URP: убрано совместное применение MSAA и пост-сглаживания; MSAA1, FXAA/SMAA остаются по качеству. Разрешения теней512/1024/2048 вместо1024/2048/4096, каскады1/2/2 вместо1/2/4, дальности24/35/45м. Масштаб мира0,70/0,85/1,00; HUD сохраняет экранную чёткость, освещение/HDR не отключены.
- Капсула врага кэшируется, рывок не вызывает GetComponent для каждого врага каждый кадр. Неизменный размер модели больше не записывается в Transform каждый кадр.
- Spatial hash толпы кэширует ID и позиции за проход. Убраны повторные полные обходы из видимости уже начатых предупреждений; поиск слота атаки заканчивается при достижении лимита. Уже начатые атаки сохраняют телеграфы даже при последующем уменьшении лимита.
- Статичные кнопки и неанимированный счётчик монет не записывают одинаковые Transform каждый кадр, уменьшая поводы для перестройки Canvas.

Численность врагов, экономика, урон и правила волн не урезаны ради FPS. Глобальные SyncTransforms при спавне/восстановлении сохранены, поскольку от них зависят немедленные физические запросы.

## Проверка и применение

Скопировать всю Assets/Brainrot, дождаться импорта. Для существующего проекта при необходимости Tools → TungTung → Обновить графику и материалы. Новая подпись производной автоматически обновляет Оркаладона. Сначала попробовать среднее качество; низкое дополнительно снижает нагрузку мира без уменьшения разрешения HUD.

Статически114C#безошибок,32Python-теста (включая геометрию) проходят. Добавлены PlayMode-регрессии бюджета сетки, неподвижного UI и предупреждений атак. Unity/PlayMode/GPU/FPS здесь не запускались. Проценты выше описывают объём геометрии, а не обещанный прирост FPS.

Для реального сравнения использовать одинаковую сборку/разрешение/качество и одну волну: время кадра p50/p95, CPU/GPU, память и GC. Сравнивать отдельный player без Development Build и Deep Profile. Для CSV есть опциональная AlphaDiagnostics в development-сборке, включение -brainrotDiagnostics; это диагностика, а не режим для итогового FPS.

Оставшиеся исходные бюджеты по Blender: акула36 586tri, осьминог23 999tri, Сахур7 428tri. Дальнейшее упрощение массовой акулы и полноценные LOD стоит проверять по GPU-профилю, сохраняя риг и видимые швы UV.

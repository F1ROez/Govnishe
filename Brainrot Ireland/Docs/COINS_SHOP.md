# Монеты и магазин — 18 ноября 2026

Новый цикл: волны → подбор золотых монет → смерть → постоянные покупки → новый более сильный забег. Это замена прежнего решения без прогрессии. XP/выбор улучшений во время забега не включены.

## Монеты

Каждый убитый враг выбрасывает1(акула),3(осьминог),8(Оркаладон) отдельных золотых монет, каждая приносит1. Объёмная монета подпрыгивает, вращается, мягко покачивается, ускоряется к игроку в радиусе3м и короткой дугой уходит к герою. Значение начисляется в постоянный кошелёк после анимации подбора. Монеты, достигшие героя в одном кадре, сохраняются одной транзакцией, чтобы не делать отдельную запись на диск для каждой монеты в группе. Звон монет слегка повышает тон в серии; HUD показывает кошелёк и заработанное за забег с коротким откликом цифры. Сердечки осьминога сохранены отдельно.

Монеты на земле не исчезают по таймеру. Пул ограничен512предметами; при переполнении заменяется самая старая неподобранная монета без начисления. Неподобранные монеты теряются при завершении попытки. Начисление происходит только после подбора; ошибка записи кошелька оставляет предмет для повторной попытки. Квитанции профиля защищают от повторного начисления одной монеты в текущем забеге.

Настройки GameBalance → «Монеты за врагов»: количество и радиусы. Максимум кошелька1млрд, квитанций одного забега16384 — пределы альфы. Сохранение самой попытки выключено по новому заданию владельца.

## Магазин

Доступен в главном меню и на экране смерти. Четыре улучшения, максимум5уровней:

| Улучшение | За уровень | Первая цена |
|---|---|---|
| Крепкая бита | +5 урона | 30 |
| Запас прочности | +15 максимального HP | 50 |
| Лёгкие ноги | +0,3 скорости | 45 |
| Быстрый рывок | −0,12с перезарядки рывка | 60 |

Следующая цена округляется вверх от базовой×1,65^текущий_ранг. Покупка списывает монеты и сохраняет ранг вместе; при ошибке записи оба изменения откатываются. Бонус постоянный: действует во всех волнах и следующих забегах, не требует повторной покупки. Магазин доступен между попытками. Выход из игры в меню завершает попытку, вернуться в её середину нельзя.

Вкладка скинов подготовлена, покупок/выбора пока нет — модели предоставит владелец.

## Интерфейс

Меню/пауза/настройки/магазин/результат используют общие песочные панели, тёплое дерево и бирюзовые кнопки; тяжёлые золотые рамки не возвращены. Главное меню использует чистый тропический фон. Клавиши сильного удара/рывка сокращены до небольших бейджей под иконками, Shift/V — две строки без широкой панели.

## Установка и проверка

Остановить Play, закрыть Unity, сохранить резервную копию. Заменить Assets/Brainrot из нового ZIP. Дождаться импорта/компиляции; сцены пересоздавать не нужно. Существующие монеты/рекорды не нужно вручную сбрасывать.

Проверить: убийство каждого вида → подбор → смерть → магазин → покупка → новый забег; покупку при недостатке денег; максимум ранга; новый забег с постоянным бонусом после покупки; закрытие приложения после подбора; завершение попытки при возврате в меню; отсутствие повторных начислений; вкладку скинов; обычный/сильный удар и его перезарядку.

В окружении нет Unity. Статический анализ/тесты Python инструментов выполнены; PlayMode-регрессии кошелька, отказа диска, рангов, coin pickup, постоянных бонусов и защита от повторного начисления добавлены, но **не запускались**.

# Архитектура

Единственная сцена запуска содержит GameManager. Awake создаёт детерминированный остров, игрока, камеру, системы и Canvas. Главное меню и игра используют один мир; повторный забег не перезагружает сцену.

GameManager владеет состояниями Menu / Playing / Paused / Upgrade / Dead. Только Playing продвигает таймер, AI и спавн. UI и уведомления используют unscaled time. При потере фокуса приложения игра ставится на паузу.

PlayerController: CharacterController, движение относительно камеры, спринт, рывок с короткой неуязвимостью, ограничение островом. CombatSystem: секторная атака через список активных врагов, крит, дополнительные удары, вампиризм, огненный бонус и радиальная ударная волна. Физический поиск врагов не используется.

EnemySpawner: пулы по типам, линейный проход AI без NavMesh; прямое преследование подходит арене без препятствий. Декорации не блокируют движение. Ограничение 140 врагов Windows / 60 Android и 4 места боссов. AI O(N), атака O(N); нет O(N²) разделения толпы.

BossSystem: мини-босс каждые120 секунд, KING каждые300, предупреждение за12 секунд. Враг реализует фазы телеграфа, рывка, расширяющейся волны, призыва и области в зафиксированной позиции игрока.

UpgradeDefinition: ScriptableObject, 12 видов, редкость, величина, предел ранга. UpgradeSystem: взвешенный выбор без повторов, очередь повышений. После максимальных рангов остаётся лечение. Build Game сохраняет каталог в Resources/Upgrades; при отсутствии использует встроенные определения.

SaveSystem: JSON в persistentDataPath, временный файл и резервная копия. Независимые рекорды времени, убийств и уровня. Настройки громкости, чувствительности и качества.

WorldBuilder / CharacterVisual / HitEffects: процедурные геометрия, общий кеш материалов, анимация частей и пул частиц. Пользовательскую модель следует размещать вместо визуального дочернего объекта, сохраняя gameplay-компоненты и API CharacterVisual.

UIManager: uGUI, Canvas 1280×720 с масштабированием, меню и touch-контролы. Android использует левый виртуальный стик, область поворота справа, кнопки атаки/бега/рывка.

Editor GameBuilder: URP renderer и pipeline, включение динамических шейдеров, editable upgrade assets, шаблон prefab акулы, сцена и команды сборки. Runtime модели создаются фабриками; prefab — начальная точка для дальнейшего art pipeline.

# Настройка острова

Откройте **Tools → TungTung → Настройки игры**. Профиль сохраняется в `Assets/Brainrot/Generated/Resources/GameBalance.asset`; повторная генерация игры не перезаписывает его. Правки самого asset сохраняются и в Play mode, отмена — Ctrl+Z. Для повторяемого теста начинайте новый забег после изменения настроек.

## Исследование и население

| Параметр по умолчанию | Значение |
|---|---|
| Обнаружение игрока | 12 м, только в своей зоне |
| Потеря интереса | 20 м |
| Поводок от места появления | 25 м |
| Радиус прогулки / скорость | 6 м / 0,8 м/с |
| Ожидание на месте | случайно1,5–4 с |
| Дистанция появления от игрока | случайно14–27 м |
| Интервал новых появлений | случайно3–6 с |
| Начальное население зоны | до4 врагов при входе |
| Лимит текущей зоны | 10 |
| Сохраняется в каждой покинутой зоне | до8 |
| Общий бюджет ПК / Android | 80 /40 |

Начальное заселение не использует номер волны и не спавнит врагов перед лицом. Кандидаты проверяются по суше, зоне и расстоянию. Если корректной точки нет, появление пропускается. В другой зоне новые враги не создаются. Старые жители остаются спокойными; при малом общем бюджете часть возвращается в пул, освобождая место текущей зоне.

Сложность растёт по зоне, не по времени забега. Каждая зона имеет отдельный вид врага. В разделе вида настраиваются здоровье, урон, скорость, подготовка и восстановление, рывок, сопротивление отбрасыванию и опыт. Враги могут заметить ударившего их игрока чуть дальше радиуса обнаружения, но всё равно соблюдают зону и поводок.

## Бой и персонаж

В «Боевая система» доступны сектор/дальность обратной связи, отбрасывание, красная вспышка, длительность взмаха и задержка контакта. Общий множитель отбрасывания2 усиливает и старые сохранённые базовые значения. Видимая длина биты и шлейфа следует текущей дальности удара.

В `Generated/Resources/DefaultCharacter.asset` задаются название, цвет, масштаб, ссылка на оружие, особенности и флаг собственных характеристик. По умолчанию общие настройки игрока берутся из GameBalance. При включении собственных статов используются характеристики персонажа, включая движение, камеру и рывок. Пользовательский выбор фиксации камеры из Settings/V имеет приоритет над стандартом профиля.

В `WoodenBat.asset` задаются множители урона, дальности, интервала и отбрасывания. Тайминг берётся из общего профиля, пока не включён флаг собственных настроек взмаха. Для будущей способности создаётся наследник PlayerAbilityDefinition: CreateRuntime возвращает отдельное состояние на забег с Tick/OnAttack/OnDamageTaken/Dispose. Общие ScriptableObject-ассеты не должны изменяться во время применения способности.

## Опыт и оформление

Стоимость уровня: `FirstLevelXp + XpLinearGrowth × (level−1) + XpQuadraticGrowth × (level−1)²`. Сохранённая система12 улучшений работает; русские карточки показывают реальные бонусы с учётом множителя. Индивидуальные upgrade assets находятся в `Assets/Resources/Upgrades` и сохраняются после Build Game.

Старые поля волн/боссов оставлены в данных для совместимости, скрыты в редакторе и не используются в новой игре. Настройки океана применяются при новом входе в Play mode. Сохранённые старые рекорды и настройки не удаляются.

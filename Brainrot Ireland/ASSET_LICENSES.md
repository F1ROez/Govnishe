# Происхождение ресурсов

Окружение острова, материалы, водный/небесный шейдеры, UI-иконки и синтезированные звуковые сигналы созданы для проекта программно. Модели персонажей предоставлены владельцем; исключения и лицензии перечислены ниже. Платные ассеты не использованы.
Unity packages распространяются Unity по своим лицензиям; встроенный шрифт LegacyRuntime.ttf поставляется Unity. Названия мем-персонажей взяты из задания владельца; отдельные сторонние изображения/аудиозаписи не импортировались.

## Модель, предоставленная владельцем

По прямому заданию владельца используется FBX ZAHUR и три текстуры из его репозитория F1ROez/Govnishe, папка tung-tung-tung-sahur-not-ai. Оригиналы сохранены; копии в Assets/Brainrot/Art/Sahur побайтно совпадают с оригинальными Git blobs. Эта модель и её текстуры не являются процедурными ресурсами, созданными агентом. Готовая Idle-анимация взята из FBX; костные клипы Walk/Sprint и runtime-взмах подготовлены для этого проекта.

## Модели врагов, предоставленные владельцем

Использованы `tralalero-tralala/source/tralalero tralala.fbx`, его `textures/shaded.png` и `blueberrinni-octopusini-animated/source/Blueberrinni Octopusini.fbx` из F1ROez/Govnishe по прямому поручению владельца. Оригинальные папки репозитория сохранены; копии в Art/Enemies имеют те же Git blob SHA. Эти модели не созданы агентом. Idle/Walk осьминога взяты из FBX, риг/походка/выпад акулы созданы в генераторе. Оптимизированные Unity-меши генерируются в Generated/Enemies.

## Округлый шрифт

`Art/Fonts/Resources/IslandRounded.ttf` — статическая производная Nunito (вес800), кириллица проверена по таблице cmap. Исходник: https://github.com/google/fonts/tree/main/ofl/nunito, Copyright2014 The Nunito Project Authors. Лицензия SIL Open Font License1.1 сохранена в `Art/Fonts/OFL.txt`. Производная переименована в Island Rounded/IslandRounded-ExtraBold. Текстуры кнопок, иконки биты/рывка/сердца/молнии оригинальные и создаются CartoonUI во время запуска; внешние изображения не использованы.

## 2026-11-14 — яркий стиль и плечевая камера

Новая модель OctopusToy получена из предоставленного владельцем blue-berryni-octopusini-ai-no-rig/source/tripo_pbr_model_2bb15eb5-b692-4bf2-84e7-08c55352ab80 (1).glb. Оригинальный GLB в репозитории не изменяется. Blender экспортировал облегчённую производную FBX (19022 вершины/23999 треугольников вместо500000 исходных треугольников); OctopusAlbedo.jpg — исходная встроенная baseColor JPEG из GLB. Глаза созданы из Unity primitives, материалы/ToonCharacter.shader оригинальные. Старый animated Octopus сохранён в Art/Enemies/Octopus как резервный источник; новая копия OctopusToy имеет приоритет.

## Иллюстрированный UI и музыка

TropicalUIAtlas.png и TropicalMenuBackdrop.png созданы image generation для этого проекта по художественному направлению референсов владельца. Это оригинальная графика без встроенных игровых надписей/чисел. JSON задаёт прямоугольники sprites; исходные PNG не нарезаются и не масштабируются при импорте. Пользовательский MenuBackground не удаляется и имеет приоритет над новым фоном.

Шесть MP3 из папки music, root «музыка для меню1.mp3» и «кнопки.mp3» предоставлены владельцем через F1ROez/Govnishe по прямому запросу на использование. Копии в Art/Audio/Resources/Audio побайтно совпадают с оригинальными Git blobs. Музыка и эти записи не созданы агентом и не объявляются ресурсами под лицензией проекта. Имена пользовательских исходников и исходные папки сохранены.

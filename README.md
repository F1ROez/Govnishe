# Брейнрот Ирландия

Маленький остров, обычные акулы из океана. Теперь с волнами (тихое начало/конец, пик в середине), короткой и сильной атакой. Короткий ЛКМ без толчка; удержание0,6с и отпускание — усиленный удар с физическим кувырком. Погибшие тела остаются на несколько секунд. Прокачка и боссы отключены.

Обновить Assets/Brainrot с объединением/заменой файлов → START_UNITY_DX11.bat → Tools/TungTung/Создать или обновить игру → BrainrotIreland → Play. Версия Unity6000.3.11f1, настройки в Tools/TungTung/Настройки игры.

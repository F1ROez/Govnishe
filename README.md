# Брейнрот Ирландия

Маленький остров, акулы и синий осьминог, волны с ожиданием зачистки, обычный/сильный удар, стамина и отдельное русское меню с продолжением забега.

## Обновление

Закрыть Unity → скопировать **Brainrot Ireland/Assets/Brainrot** из свежего ZIP в свою Assets с объединением папок/заменой файлов → START_UNITY_DX11.bat → дождаться импорта → **Tools/TungTung/Создать или обновить игру** → MainMenu → Play. Существующие Generated и настройки сохраняйте.

Подключена модель владельца ZAHUR из tung-tung-tung-sahur-not-ai, исходники сохранены. Build Game автоматически создаёт текстурированный prefab и анимационный контроллер: Idle из FBX, временные костные ходьба/бег/взмах. Исправлены сброс физической позиции врагов при спавне, ввод паузы и ширина подписей редактора. Обновлены вода, свет и небо.

[Подробнее](<Brainrot Ireland/README.md>) · [Параметры](<Brainrot Ireland/GAME_SETTINGS.md>)

Модель проверена через Blender, исходники проверены статически. Unity Editor в облаке отсутствует: Unity-компиляция, шейдеры и игровые регрессии требуют проверки на ПК владельца.

# Brainrot Ireland

Unity6 / URP17.3, Windows PC и Android. Проект находится в папке **Brainrot Ireland**.

Обновление: закройте Unity, скопируйте всю Brainrot Ireland/Assets/Brainrot в Assets своего проекта с заменой (включая .meta, PNG/JSON/MP3). Дождитесь импорта и выполните Tools → TungTung → Создать или обновить игру. Откройте MainMenu, нажмите Play. Настройки баланса и пользовательские исходники сохраняются.

Новое: иллюстрированный UI по референсу — морские рамки с портретом/HP, деревянная табличка волны, высокие карточки способностей, круглые звук/пауза, широкая панель управления. Меню — woodlogo слева, деревянные кнопки справа, золотая «Продолжить»; пауза без синей заливки. Подключены 6 игровых песен из music в случайном порядке без повторов до конца цикла, отдельная зацикленная музыка меню и звук кнопок. При паузе/выходе в меню позиция игрового трека сохраняется. Mute не стирает выбранную громкость.

Исправлена ошибка Material doesn't have color property _Color для ToonCharacter. Новые модели, плечевая камера, волны, стамина и бой сохранены.

Исходные MP3/модели в корне репозитория не изменены. Подробнее: README/DEVELOPMENT_LOG/ASSET_LICENSES внутри проекта. 55 C# исходников прошли статическую проверку, 34 теста подготовлены; MP3 проверены ffprobe и Git SHA. Unity-компиляция, воспроизведение, PlayMode и итоговый кадр в облаке не выполнялись.

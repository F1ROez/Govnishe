# Brainrot Ireland

Unity **6000.3.11f1 / URP 17.3**, C#. Исходный проект находится в папке **Brainrot Ireland**. Этот ZIP — Unity-проект, а не готовая Windows-игра.

В текущем обновлении: продолжение забега после перезапуска с автосохранением, раздвижение толпы, столкновения камеры с окружением, обновлённые материалы/свет/вода, обучение, рекорд волны и испытания, события с четвёртой волны, панели паузы/настроек по последним референсам. Прокачка и боссы отключены. Исходные модели и музыка владельца сохранены.

## Обновление своего проекта

1. Закройте Unity и распакуйте свежий ZIP ветки `codex/brainrot-ireland`.
2. Скопируйте **Brainrot Ireland/Assets/Brainrot** в **Assets** своего проекта с заменой, включая `.meta`.
3. Откройте проект, дождитесь импорта и выполните **Tools → TungTung → Создать или обновить игру**. Это обновит профиль света v4 и материалы.
4. Откройте MainMenu и нажмите Play.

Для полной проверки/упаковки скопируйте также папки `Tools` и `Docs` из папки проекта. На Windows `Tools/CheckAlpha.cmd` запускает проверку через установленный Unity Editor и создаёт player ZIP только при успешном прохождении реальных этапов. Нужны Python 3, Unity Editor и Windows Build Support. Перед batch-запуском закройте этот проект в Editor.

## Фактический статус

Статически проверены **86 C# файлов**, ошибок синтаксиса/метаданных нет. **10 Python-тестов утилит** прошли на искусственных данных. Unity Editor в рабочей среде недоступен: C#-компиляция Unity, HLSL, EditMode/PlayMode, Windows-сборка, длительная игра и FPS/память **не проверены**. Точное совпадение интерфейса в Unity требует проверки по реальным скриншотам.

Лицензия шрифта присутствует. Разрешения на распространение пользовательских моделей и песен ещё не подтверждены; публичный выпуск требует проверки прав и приёмки сборки.

# Brainrot Ireland

Unity **6000.3.11f1 / URP 17.3**, C#. Проект находится в папке **Brainrot Ireland**. Этот ZIP содержит исходники Unity, а не готовую Windows-игру.

Обновление полировки: выразительный сильный удар с подготовкой/возвратом камеры, белым шлейфом, ограниченной отдачей и отдельными звуками; конечный бюджет и полоска прогресса волны, зачистка, до трёх боковых карточек испытаний. Доработаны солнечный toon-свет, влажный берег, пена воды, материалы и реальные профили качества. Исправлены сохранение резервной копии и сброс повторного забега. Прокачка и боссы отключены. Оригинальные модели и музыка владельца сохранены.

## Обновление

1. Закройте Unity, сохраните резервную копию проекта и распакуйте ZIP ветки `codex/brainrot-ireland`.
2. Скопируйте **Brainrot Ireland/Assets/Brainrot** в **Assets** своего проекта с заменой файлов, включая `.meta`. Не удаляйте свои модели и существующий `Assets/Brainrot/Generated/Resources/GameBalance.asset`.
3. Для автоматических проверок обновите также папки `Tools` и `Docs` из папки проекта.
4. Откройте проект и дождитесь импорта. Выполните **Tools → TungTung → Создать или обновить игру**. Профиль света обновится до v5, пользовательский GameBalance сохранится.
5. Откройте `Assets/Scenes/MainMenu.unity` и нажмите Play.

## Проверка

Статический валидатор: **97 C# файлов, 0 синтаксических/структурных ошибок**. **17 Python-регрессий утилит** прошли. Unity Editor в рабочей среде отсутствует: компиляция C#/HLSL в Unity, EditMode/PlayMode, Windows-сборка, реальный вид/ощущения, FPS и длительная игра **не проверены**.

На ПК с Unity запустите `Tools/CheckAlpha.cmd` при закрытом редакторе: он выполняет реальные этапы Unity и проверяет Windows ZIP по полному manifest файлов. Отсутствие Unity даёт BLOCKED, а не PASS. Нужны Python3, Unity Editor и Windows Build Support.

Права на предоставленные модели и музыку ещё не подтверждены документами; публичный релиз требует проверки прав и готовой сборки.

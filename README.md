# Брейнрот Ирландия

Большой остров с пятью зонами и собственными врагами: пляж/акулы, луга/Лирили Ларила, лес/Патапим, руины/Капучино Ассасино, болото/Бомбардиро Крокодило. Волны и боссы отключены. Враги появляются только в зоне игрока и замечают его вблизи. Интерфейс и настройки на русском, есть карта на M и белый шлейф биты.

![Схема процедурной карты — не скриншот Unity](<Brainrot Ireland/Docs/ISLAND_MAP.svg>)

## Запуск

Скачайте эту ветку через **Code → Download ZIP**. Нужная Unity-папка — вложенная **Brainrot Ireland** с Assets/Packages/ProjectSettings. Разместите по короткому пути `C:\UnityProjects\BrainrotIreland` и запустите **START_UNITY_DX11.bat**. Unity **6000.3.11f1**. После импорта **Tools → TungTung → Создать или обновить игру**, открыть **Assets/Scenes/BrainrotIreland.unity**, Play → **ИГРАТЬ**.

Для обновления работающей копии достаточно скопировать **Assets/Brainrot** из свежего архива в свою **Assets**, объединив папки и заменив файлы. Старую папку предварительно не удаляйте; сохраните Generated и Assets/Resources/Upgrades. Library/ProjectSettings/Packages менять не нужно.

**Tools → TungTung → Настройки игры** — параметры зон, обнаружения, спавна, боя и прокачки.

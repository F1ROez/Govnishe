# Брейнрот Ирландия

Маленький остров, обычные акулы из океана. Зоны, волны, боссы и прокачка отключены. Сохранены новая боевая система, белый шлейф и усиленное отбрасывание.

Unity 6000.3.11f1. Обновите Assets/Brainrot, затем Tools → TungTung → Создать или обновить игру. Запуск через START_UNITY_DX11.bat.

Unity в облаке отсутствует; игровой запуск этой версии не проверен.

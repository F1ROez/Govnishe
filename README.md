# Brainrot Ireland

Unity6 / URP17.3, Windows PC и Android. Проект — в папке **Brainrot Ireland**.

Обновление: скопируйте всю Brainrot Ireland/Assets/Brainrot в Assets своего проекта с заменой, включая .meta. Дождитесь импорта Unity, затем Tools → TungTung → Создать или обновить игру. Откройте MainMenu и нажмите Play. Существующие настройки баланса сохраняются.

Последнее обновление: новая модель blue-berryni-octopusini-ai-no-rig преобразована из GLB в облегчённый FBX, добавлены большие глаза и покачивание при ходьбе. Акуле добавлены игрушечные пропорции и яркий toon-материал. Интерфейс ярче: синие/фиолетовые панели, сочные жёлтые/бирюзовые кнопки и обводки. Камера у правого плеча, выше головы; параметры — Настройки игры → Камера от третьего лица.

Оригинальные файлы моделей в корне репозитория сохранены. Отдельный glTF-плагин не нужен. Для обновления сохранённых prefab/materials после копирования обязательно выполните Build Game. Подробные инструкции и лицензии — README/ASSET_LICENSES внутри проекта.

48 C# исходников прошли статическую проверку; модели просмотрены в Blender. Unity/HLSL/PlayMode и производительность в облаке не проверялись.

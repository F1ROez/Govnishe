# Брейнрот Ирландия

Маленький остров, акулы и синий осьминог, волны с ожиданием зачистки, две атаки, физические тела, стамина и русское меню в отдельной сцене. Продолжение текущего забега работает после выхода в меню, новая игра сбрасывает его. Тела остаются4 секунды; захват осьминога запрещает только удары, движение доступно.

Обновить Assets/Brainrot с объединением/заменой файлов → START_UNITY_DX11.bat → Tools/TungTung/Создать или обновить игру → открыть **Assets/Scenes/MainMenu.unity** → Play. Unity6000.3.11f1. Генератор создаёт обе сцены и включает меню первым в сборке.

Фон из сообщения пока недоступен как файл: в GitHub временно цветной фон. Для точного изображения нужен PNG/JPG или ZIP с ним. Команда Tools/TungTung/Установить фон меню импортирует локальный файл и сохраняет пропорции на экране.

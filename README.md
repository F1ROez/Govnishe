# Brainrot Ireland

Unity6 (6000.3.11f1), URP17.3, Windows/Android. Маленький остров, акулы и Blueberrinni Octopusini, волны, бита, сильный удар, рывок и стамина. Прокачка/боссы отключены по текущему заданию.

## Открыть и обновить

1. Скачайте ZIP ветки `codex/brainrot-ireland`. Unity-проект находится внутри папки **Brainrot Ireland** (рядом Assets/Packages/ProjectSettings).
2. Для обновления существующего проекта закройте Unity и скопируйте **Brainrot Ireland/Assets/Brainrot** целиком с заменой, включая Art/Fonts/Shaders/Editor/Runtime и все .meta. Пользовательские Generated/GameBalance и MenuBackground сохраняются.
3. Откройте проект, дождитесь импорта. **Tools → TungTung → Создать или обновить игру** создаст обе сцены, материалы, оптимизированные prefabs всех3 персонажей и профиль освещения.
4. Откройте MainMenu и нажмите Play. Новая игра / Продолжить игру сохраняют текущий сценарий.

## Визуальное обновление

Модели Tralala/Octopus взяты из папок владельца без изменения оригиналов. Octopus использует готовые Idle/Walk;595 частей объединены в1 skinned renderer. Акуле создан трёхногий риг, походка и визуальный укус. Новое оформление UI, оригинальные иконки/кнопки/полосы, округлый OFL-шрифт с кириллицей, мягкий солнечный и небесный свет, океан/прибой/небо/пальмы/песок. Размеры моделей доступны через Настройки игры.

Контроль:48 C# файлов прошли статическую проверку;29 тестов подготовлены. Модели прочитаны и просмотрены в Blender. Unity-компиляция, PlayMode/HLSL, оценка визуала на устройстве и FPS в облаке не выполнялись. Подробности — README/DEVELOPMENT_LOG/ASSET_LICENSES внутри проекта.

# Brainrot Ireland

Unity6 / URP17.3, Windows PC и Android. Проект — в папке **Brainrot Ireland**.

Обновление: закройте Unity, скопируйте всю Brainrot Ireland/Assets/Brainrot в Assets своего проекта с заменой, включая .meta. Дождитесь импорта и обязательно выполните Tools → TungTung → Создать или обновить игру. Это обновит сохранённый профиль освещения и toon-материал игрока. Откройте MainMenu и нажмите Play.

Последняя итерация: компактные иллюстрированные HUD/иконки/кнопки (примерно на25–35% меньше), тонкая нижняя подсказка, яркий дневной стиль с бирюзовой водой, лаймовыми пальмами, кремовым песком и светлыми мягкими тенями. Старое затемнение/виньетка профиля автоматически заменяются один раз при Build Game; дальнейшие ручные настройки сохраняются. Все персонажи используют согласованные мультяшные материалы.

Шесть игровых песен в случайном порядке, loop меню, звук кнопок, новые модели, плечевая камера, волны, стамина и бой сохранены. Исходники музыки/моделей не меняются.

56 C# файлов прошли статическую проверку;35 тестов подготовлены. Unity-компиляция/HLSL/PlayMode и итоговый кадр в облаке не выполнялись. Подробности в README/DEVELOPMENT_LOG внутри проекта.
